# Portfolio Minimaliste - TIDATOA Diminine Richard (s_richard)

Portfolio personnel moderne, inspiré de l'esthétique minimaliste et sombre de [DarkMinimal](https://darkminimal.vercel.app/). Développé avec **Next.js 14**, **TypeScript** et **Tailwind CSS**.

## ✨ Caractéristiques

- 🌙 **Design Dark Minimaliste & Épuré** : Palette sombre (`#101010`), accents violets néon (`#a476ff`) avec reflets animés (`shiny-sec`) et indicateurs lumineux.
- ⚡ **Navigation Flottante Intuitive** : Barre dynamique rétractable sur défilement pour bureau et dock ergonomique pour mobile.
- 👾 **Effet Digital Matrix LetterGlitch** : Canvas haute performance avec pluie de symboles et interpolation fluide de couleurs.
- 🔄 **LogoWall Défilant à l'Infini** : Marquee continu des technologies clés (Next.js, React, TypeScript, Tailwind, Node.js, Python, Supabase, Git, etc.).
- 📂 **Présentation des Réalisations** : Grille avec filtres dynamiques, aperçus, badges d'état et liens vers le code source GitHub et démos en production.
- 🛠️ **Expertise Déroulante (What I Do)** : Accordéon interactif détaillant les domaines d'intervention technique.
- 💬 **Formulaire & Contact Direct** : Prise de contact facile, lien direct WhatsApp, téléphone et email avec copie en un clic.
- ❤️ **Bouton Like Interactif** : Animation d'impulsion cardiaque et persistance du compteur en `localStorage`.
- 🎵 **Intégration Ambiance Spotify** : Widget audio intégré pour coder dans les meilleures conditions.

## 🚀 Démarrage Rapide

```bash
# Installation des dépendances
npm install

# Démarrer le serveur de développement
npm run dev

# Compiler pour la production
npm run build

# Démarrer en production
npm start
```
