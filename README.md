## 🚀 Lancer en Local

```bash
# 1. Cloner le projet
git clone https://github.com/TIDATOArichard/portfolio.git
cd portfolio

# 2. Installer les dépendances
npm install

# 3. Démarrer le serveur de développement
npm run dev

# 4. Compiler pour la production
npm run build

# 5. Lancer la version compilée
npm start
```
